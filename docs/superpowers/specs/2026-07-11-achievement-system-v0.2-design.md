# Earth Online 成就系统 v0.2 设计

日期：2026-07-11

状态：设计已完成，等待用户最终审阅

本文件取代 `2026-07-10-achievement-system-design.md` 中与首期范围、昼夜切换、旧存档确认、稀有度和达成率有关的旧决策。

## 1. 产品定位

成就系统不是游戏化奖励中心，而是玩家的人生夜间档案馆。

- 白天系统负责每日任务、等级、经验和运行状态。
- 夜间系统负责旧存档、人生记录、称号和成就展示。
- 成就不发放经验、金币或抽奖次数。
- 成就的价值来自记录、展示、称号与身份标签。
- 整个功能保持本地优先，不依赖账号或服务器。

产品内名称为“夜间档案馆”。界面不使用 SSR、装备、战力等传统游戏术语。

## 2. 首期范围

首期不一次性制作全部 49 项成就，而是完成 12 项可真实体验的样板：

1. 学有所成
2. 驾照猎人
3. 厨艺觉醒
4. 初恋支线
5. 第一份工
6. 海外打卡
7. 真心羁绊
8. 自我救赎
9. 守住热爱
10. 山野露营
11. 财富自由
12. 全款置业

这 12 项必须完整覆盖昼夜切换、旧存档确认、成就墙、详情、解锁通知、隐私和五档稀有度。确认视觉与交互后，剩余 37 项沿用同一模板扩展。

## 3. 昼夜双系统

白天面板和夜间档案馆是同一个 Earth Online 世界的两个状态，不是两个独立网页。

### 3.1 固定入口

- 清晨面板右上角显示克制的月相图标。
- 夜间档案馆同一位置显示太阳图标。
- 图标只负责昼夜切换，不承担普通导航菜单功能。
- 图标必须有工具提示和键盘焦点状态。
- 每日任务始终留在白天系统，成就浏览始终留在夜间系统。

### 3.2 进入夜间档案馆

1. 清晨面板文字和玻璃边框轻微失焦并淡出。
2. 镜头拉远，重新显露真实 3D 地球。
3. 地球转向夜半球，昼夜分界线掠过地表。
4. 城市灯光逐步点亮，轨道信号保持低噪音。
5. 深蓝外框稳定后，黑金档案内容从夜侧城市信号中浮出。

返回白天时按相反方向执行。禁止用普通整页淡入淡出代替地球昼夜变化。

### 3.3 动画时长

- 玩家第一次进入夜间档案馆：约 2.4 秒。
- 当天第一次再次切换：约 1.3 秒。
- 当天后续切换：约 0.7 秒。
- 动画过程中再次点击入口：立即完成当前切换。
- 开启“减少动态效果”：使用约 0.25 秒的光照与颜色过渡。

动画结束前不允许重复创建面板实例。切换失败时恢复到进入前的完整状态，不留下黑屏或无法退出的遮罩。

## 4. 夜间档案馆视觉

夜间界面保持 Earth Online 的深蓝地球外层，黑金只集中在成就内容，不把整个页面涂成金色。

- 背景：真实夜半球、稀疏城市灯光、少量轨道信号。
- 外层框架：深蓝、低反射、薄边界。
- 成就卡：近黑背景、金属图标、白色标题、低亮度描述。
- 动效：只让稀有成就产生极慢微光，普通成就保持静止。
- 卡片最大圆角 8px，避免手游式大圆角和厚重发光。
- 桌面优先使用长卡列表；手机改为紧凑列表，不做横向轮播。

## 5. 旧存档流程

旧存档采用“系统初筛 + 玩家确认 + 完整图鉴补录”。系统不要求证明，也不替玩家判断人生价值。

### 5.1 初筛

系统根据初始建档中的年龄、学历、工作、关系、经历和兴趣信号生成候选成就。建档问题只负责收集必要信号，不直接展示 49 项长问卷。

第一次进入夜间档案馆时显示：

> 旧存档扫描完成  
> 发现若干条可能存在的历史记录

### 5.2 玩家确认

- 候选成就按人生章节分组。
- 每项可选择“确认收录”或“暂不收录”。
- 玩家可进入完整图鉴主动认领系统未发现的经历。
- 已收录成就可撤销，撤销不扣除任何资源。
- 涉及感情、经济、家庭、健康等内容时，不自动标记敏感。
- 是否隐藏、展示或参与解锁仪式完全由玩家决定。

### 5.3 首次恢复仪式

- 确认完成后，只选一个代表成就播放完整 Steam 式解锁动画。
- 其余成就合并为一叠金色档案，显示“旧存档已恢复，新增 N 项人生记录”。
- 不连续播放多个大型弹窗。
- 代表成就必须来自允许展示且允许聚焦的记录。

## 6. 成就墙与详情

成就墙默认按照人生章节浏览，并支持“全部、已收录、未收录、隐藏”过滤。

每张长卡展示：

- 成就图标
- 标题
- 一句描述
- 全球玩家记录率
- 收录状态
- 稀有度材质

点击卡片打开详情。详情允许修改：

- 是否收录
- 是否隐藏
- 是否允许出现在个人展示区
- 是否允许参与代表成就仪式

未收录成就可以显示名称和条件。需要保留惊喜的特殊成就使用封存纹章，标题和条件均不提前显示。

## 7. 解锁通知

运行期间达成新成就时，使用低干扰的 Steam 式通知：

- 从右下角或移动端底部进入。
- 先显示金属图标，再显示标题与记录率。
- 普通成就约 3.5 秒后自动收起。
- 极稀有成就在打开详情时额外播放一次克制的呼吸光晕。
- 通知不得遮挡每日任务的主要操作按钮。
- 同时达成多项时进入队列，不重叠弹出。

## 8. 稀有度系统

稀有度必须在成就墙上一眼可辨，但保持同一黑金材质体系，不使用白蓝紫橙品质色。

| 全球玩家记录率 | 层级 | 缩略图表现 |
| --- | --- | --- |
| 50% 及以上 | 常见记录 | 哑光铜金，静止，简单边框 |
| 20% 至 49.9% | 珍贵记录 | 清晰亮金，双层细边框 |
| 5% 至 19.9% | 稀有记录 | 月白金，极慢反光，精细纹样 |
| 1% 至 4.9% | 极稀有记录 | 冷铂金，微弱城市灯点脉冲 |
| 低于 1% | 世界级记录 | 独立档案纹章与一次性入场光晕 |

界面不显示“普通、SSR”等文字标签。玩家通过材质、边框和记录率理解稀有程度。

## 9. 全球玩家记录率

本地版本没有真实全服统计。数据定义为：

> 基于地球人口与人生经历模型生成的世界观估算值

规则：

- 每项成就的记录率写入版本化成就定义，刷新页面和日期变化不会改变。
- 普通卡片只显示百分比。
- 信息图标统一解释这是系统估算，不在每张卡重复免责声明。
- 未来接入真实统计时复用同一字段和 UI。

## 10. GPT Image 2 素材规范

现有 49 张截图只作为题材和构图参考，不作为最终发布资产。

所有成就图标由 GPT Image 2 按统一母版重新生成：

- 1:1 正方形，建议 1024 x 1024 原图。
- 纯黑或近黑背景。
- 单一中心主体，四周保留约 12% 安全区域。
- 统一金色线描和固定线宽。
- 人物使用无明确身份的抽象人形。
- 星芒数量和位置保持克制。
- 不生成文字、数字、百分比和奖杯标签。
- 不使用摄影、复杂 3D、霓虹渐变或厚重外发光。
- 图标缩小到 64px 时仍能识别主题。

标题、描述、百分比、边框和稀有度全部由 HTML/CSS 渲染。每张生成图需经过缩略图可读性和风格一致性检查后才进入项目。

## 11. 数据边界

静态成就定义与玩家收录状态分离。

```js
{
  id: "driver-license-hunter",
  title: "驾照猎人",
  description: "通过驾考专属副本，解锁机动车驾驶权限。",
  category: "exploration",
  rarityPercent: 53,
  iconAsset: "driver-license-hunter.webp",
  oldSaveSignals: ["has_driver_license"]
}
```

```js
{
  achievementId: "driver-license-hunter",
  unlockedAt: "2026-07-11T12:00:00.000Z",
  source: "old_save_confirmed",
  hidden: false,
  displayable: true,
  spotlightAllowed: true
}
```

导入旧版本存档时保留已有成就记录。未知成就 ID 不删除，作为兼容记录保存。导入失败不得覆盖当前本地存档。

## 12. 验收标准

首期完成必须同时满足：

1. 12 项成就在桌面和手机上都能完整浏览。
2. 稀有度在不阅读文字时也能大致辨认。
3. 昼夜切换无黑屏、卡死、重复面板和无法退出状态。
4. 首次完整动画、后续加速和减少动态效果均可验证。
5. 旧存档可以确认、跳过、主动补录、隐藏和撤销。
6. 批量恢复只播放一个完整代表成就。
7. 达成率刷新后保持不变。
8. 所有正式成就图标来自统一 GPT Image 2 母版，不直接使用参考截图。
9. 现有每日任务、经验、导入和导出存档功能不回归。
10. 自动化测试覆盖数据迁移、候选生成、确认、撤销、通知队列和固定记录率。

## 13. 明确延后

首期不实现：

- 真实账号与在线全服统计
- 好友比较和排行榜
- 自动验证现实经历
- 金币、抽奖和成就商城
- 49 项全部正式素材
- 大规模运行时行为追踪

这些功能不影响当前数据结构，但在首期验收通过前不进入实现范围。
